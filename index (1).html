    AutoSort Quick User Manual

    1. Turn on the AutoSort basket.
    2. Open the lid.
    3. Load clothes into the basket.
    4. Connect to the simulated smartphone controller.
    5. Select Automatic Sorting.
    6. Start the sorting demonstration.
    7. Close the lid before sanitization.
    8. Run the UV-C simulation.
    9. Activate airflow if desired.
    10. Wait for completion and remove the clothes.
    Safety reminders

    Never open the lid during a UV-C cycle (the demo interlocks it). Keep hands clear of moving parts. UV-C here is a visual representation of an experimental sanitization-assistance feature — no guaranteed sterilization or bacteria elimination is claimed.

    Conceptual simulation

    This web demo is not connected to hardware. The phone, sensors, sorting mechanism, UV-C and airflow are simulated for presentation purposes.
